## 二、人物立绘（7 张）

### 通用规格

| 项 | 值 |
| --- | --- |
| **出图尺寸** | **1024 × 1536（2:3 竖构图）** |
| 交付格式 | `.webp`，质量 80，单张 ≤ 180 KB（单文件版会把图 base64 内嵌，超了整包会很大） |
| 构图 | 半身到七分身，人物**水平居中** |
| **头部位置** | **必须落在画面上方 15% ~ 35% 的高度区间内** |
| **底部 35% 会被压暗** | 界面在图上盖了一层从下往上的深蓝渐变（35% 处已经很实，67% 处才透明），所以别把关键信息放在下三分之一 |
| 背景 | 有环境但要简洁、暗、浅景深。人物边缘要和背景拉开明暗差 |

**为什么是 2:3**：这些图会被同时塞进四种不同比例的框——弹窗立绘 300×540（5:9）、序章大图（约 0.68）、侧栏卡面 270×380（0.71）、创建页整屏左栏（约 0.74）。全部是 `object-fit: cover` + `object-position: center 18%`。2:3 是唯一四个框都能安全裁的比例，头在上方 15%~35% 是四个框都能保住脸的区间。

### ⚠️ 这两张的比例要改

现在是 **1448×1086 横图**，但它们是当作"弹窗立绘"用的，会被塞进 **300×540 的竖框**里 `cover` 裁切——横图进竖框，只剩中间一条窄缝，等于白画。这是从原作继承下来的老问题。

**所以请出竖图：1024 × 1536（2:3），和人物立绘同规格。**（下方 35% 同样会被压暗，构图往上放。）

| | 要求 |
| --- | --- |
| `world-cup-scene.webp` | 万人体育馆的**竖向纵深**：从舞台往观众席看上去，或者从观众席高处往下看舞台。中央是巨大的主屏（**屏上不要有具体画面，做成抽象光带或纯色发光**）、追光柱、漫天手幅和荧光棒。主色深蓝 + 金，气氛要**盛大到有压迫感**。<br>可以让画面下方三分之一是选手席的剪影背影——反正会被压暗，正好当前景 |
| `asian-cup-scene.webp` | 同样的场馆语言，但**规模小一号、更冷**：观众席没那么满，灯光更偏青蓝，少一点金。要能一眼看出"这不是最大的那个舞台"。可以强调场馆外的城市夜景或落地窗 |

两张必须像是同一个摄影师同一天拍的。

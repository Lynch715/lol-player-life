# 事件编写格式（两月随机事件）

游戏每 2 个月抽一个随机事件。所有事件都写在 `app.js` 的 **`const EVENTS=[ ... ]`** 数组里，往里加对象即可。

---

## 一、事件对象结构

```js
{
  id:"unique_id",                    // 必填，唯一，英文下划线
  phase:["firstteam","pro"],         // 必填，可触发的阶段（见下表）
  minAge:18,                          // 选填，最小年龄
  maxAge:30,                          // 选填，最大年龄
  weight:1,                           // 选填，权重（默认1，越大越常出现）
  once:true,                          // 选填，true=一次性剧情，永不重复
  maxMoney:60,                        // 选填，仅当资金 < 该值(万)时触发（"没钱"情境）
  minMoney:300,                       // 选填，仅当资金 ≥ 该值(万)时触发（"有钱"情境）
  notMarried:true,                    // 选填，已婚则不触发（谈恋爱期事件用）
  requireMarried:true,                // 选填，仅已婚触发（婚后生活事件用）
  condition:s=>s.national.called,     // 选填，自定义条件，返回 true 才触发
  title:"事件标题",                    // 必填
  portrait:"assets/lin-xiaoman.webp", // 选填，左侧立绘
  body:"<p>正文……</p>",              // 必填，HTML
  options:s=>[                        // 必填，2~3 个选项
    option("选项文字","后果提示",()=>{ /* 改状态 */ }),
    option("另一个选择","后果提示",()=>{ /* 改状态 */ },"danger"),
  ]
}
```

多个门槛是「与」关系：全部满足才会触发。`condition` 是万能兜底，任何逻辑都能写。

### phase 阶段取值
| 值 | 含义 | 大致年龄 |
|----|------|---------|
| `academy` | 梯队少年 | 14–15 |
| `firstteam` | 国内一线队 | 16+ |
| `overseas` | 海外青训/效力 | 16+ |
| `campus` | 校园线（放弃职业后） | 16–17 |
| `pro` | 职业生涯（转会/国家队开放） | 18+ |

---

## 二、option(选项)

```js
option(text, effect, apply, tone)
```
- `text`：按钮主文字
- `effect`：副文字，写清后果，如 `"资金+20万；声望-5"`
- `apply`：`()=>{...}` 改状态的函数（用外层 `s`）
- `tone`：选填，`"danger"`(红) / `"gold"`(金) / 省略(默认)

---

## 三、apply / condition 里能用的「工具箱」

改数值（都对当前存档 `s` 操作）：

| 写法 | 作用 |
|------|------|
| `change(s,"fitness",-10)` | 体能。字段还有 `form`状态 `morale`心情 `coachFavor`教练信任 `family`家庭 `fame`声望 `scout`球探关注（均 0–100 自动夹紧） |
| `addMoney(s,20)` / `addMoney(s,-15)` | 资金增减（万，可负） |
| `changeLove(s,8)` | 小满好感（分手/反目时无效） |
| `gainStat(s,"will",1,"story")` | 五维：`height`身高 `speed`速度 `burst`爆发 `stamina`耐力 `will`意志 |
| `gainSkill(s,"finishing",1,"finish")` | 技术：`finishing`射术 `dribble`盘带 `vision`视野 `setPiece`定位球 |
| `change(s.risks,"gambling",20)` | 风险：`gambling`赌博 `health`健康 `media`舆情 |
| `change(s.national,"adapt",10)` | 国家队战术适配 |
| `sufferInjury(s,rand(2,4))` | 造成 2–4 个月伤停 |
| `log(s,"good","一句人生记录")` | 写进人生记录。类型：`good`好消息 `bad`代价 `story`故事 `warn`提醒 |
| `unlock("ach_id")` | 解锁成就 |
| `s.flags.xxx=true` | 设自定义剧情标志，供以后事件用 `condition:s=>s.flags.xxx` 判断 |

判断/随机（可用在 `condition` 或 `apply` 里）：

| 写法 | 作用 |
|------|------|
| `chance(.4)` | 40% 概率返回 true |
| `rand(2,5)` / `pick(["A","B"])` | 随机整数 / 随机取一个 |
| `hasTalent(s,"iron_man")` | 是否拥有某天赋 |
| `overall(s)` | 综合能力 |
| `ageInfo(s).age` | 当前年龄 |
| `s.money` `s.fame` | 资金、声望 |
| `s.relationship.status` / `.love` | 关系（`恋人`/`异地`/`分手`）、好感 |
| `s.national.called` | 是否已入选国家队 |
| `s.flags.married` | 是否已婚 |

## 四、立绘（portrait，选填）

`assets/father.webp`（父亲）、`assets/lin-xiaoman.webp`（小满）、`assets/coach-zhou.webp`（周骁教练）、`assets/player.webp`（主角）。
新立绘放进 `assets/` 后直接写路径即可（如 `assets/brother-wang-v1.webp`），打包脚本会自动内联被引用的图。

## 五、完整示例

### 例1 · 梯队期，一次性的成长瞬间
```js
{id:"academy_first_paycheck",phase:["academy"],once:true,
 title:"第一笔训练补贴",portrait:"assets/father.webp",
 body:"<p>队里发了第一笔训练补贴，两百块，装在一个牛皮纸信封里。你捏着它站在宿舍楼下，第一反应是想给家里打个电话。</p><p>你爸接得很快，听你说完，沉默了两秒，说：<span class='dialogue'>“自己留着买双好点的鞋。”</span></p>",
 options:s=>[
   option("寄回家","家庭+10，意志+1",()=>{change(s,"family",10);gainStat(s,"will",1,"story");log(s,"story","你把信封原封不动寄了回去。")}),
   option("买双新球鞋","状态+5，射术+0.5",()=>{change(s,"form",5);gainSkill(s,"finishing",.5,"finish")})
 ]},
```

### 例2 · 职业期 · 有钱后才会遇到的诱惑
```js
{id:"investment_scam",phase:["pro"],minAge:22,minMoney:300,weight:1,once:true,
 title:"“稳赚不赔”的朋友项目",portrait:"assets/player.webp",
 body:"<p>一个多年没联系的老乡忽然请你吃饭，饭桌上掏出一份项目书，说带你“钱生钱”，年化写得很好看。</p><p>他反复强调：<span class='dialogue'>“就当帮兄弟一把，亏了算我的。”</span></p>",
 options:s=>[
   option("投一笔试试","投80万；60%翻倍、40%打水漂",()=>{addMoney(s,-80);if(chance(.6)){addMoney(s,160);log(s,"good","项目真的分红了，你翻了一倍。")}else{log(s,"bad","项目黄了，钱没回来。")}},"danger"),
   option("婉拒，钱放稳妥处","声望+2；错过也许的机会",()=>{change(s,"fame",2);log(s,"story","你笑着把项目书推了回去。")})
 ]},
```

### 例3 · 婚后专属事件
```js
{id:"married_anniversary",phase:["pro"],requireMarried:true,weight:1,
 title:"结婚纪念日撞上客场",portrait:"assets/lin-xiaoman.webp",
 body:"<p>纪念日当天有客场。她没提，但你记得。</p>",
 options:s=>[
   option("赛后连夜飞回去","感情+12，体能-10",()=>{changeLove(s,12);change(s,"fitness",-10)}),
   option("视频里补一句","感情+4，专注比赛状态+4",()=>{changeLove(s,4);change(s,"form",4)})
 ]},
```

## 六、小贴士
- **一次性剧情** 记得加 `once:true`，否则后期会重复触发。情境类（转会、竞争、红牌、赞助等可反复发生的）就别加，让它们循环填充后期。
- **正文** 建议 2–4 段；台词用 `<span class='dialogue'>“……”</span>`。
- **选项** 2–3 个，每个都要有真实取舍（好处+代价），别做“纯正确答案”。
- **情境匹配** 善用 `maxMoney`/`minMoney`/`notMarried`/`requireMarried`/`condition`，别让穷困事件在土豪后期弹、恋爱事件在婚后弹。
- **权重** `weight` 默认 1；想让某事件更罕见可不改，想更常见设 2–3。
- 写完把新对象粘进 `EVENTS=[…]` 数组，运行 `node tests/structure.test.mjs` 确认不报错，再 `python3 build_single.py` 重建单文件版。

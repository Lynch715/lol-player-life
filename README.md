# 模拟英雄联盟选手 · 峡谷人生

从14岁网吧少年开始的本地电竞生涯模拟游戏。改造自同一套引擎的《模拟球员 · 绿茵人生》。

**▶ 在线试玩：https://lynch715.github.io/lol-player-life/**

也可以下载[单文件版](%E6%A8%A1%E6%8B%9F%E8%8B%B1%E9%9B%84%E8%81%94%E7%9B%9F%E9%80%89%E6%89%8B-%E5%8D%95%E6%96%87%E4%BB%B6%E7%89%88.html)（约 1.6 MB，图片全部内嵌），存到本地双击就能玩，不联网。

## 启动

直接双击 `index.html` 即可游玩。也可以在本目录执行：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 已实现

- 七项主属性 REA 反应 / MEC 操作 / COM 沟通 / LAN 对线 / AWA 意识 / END 体力 / MEN 心态，首页七边形雷达图展示
- **创建时五选一分路**（上单 / 打野 / 中单 / 射手 / 辅助），选完不可改。分路只做一件事：换掉综合评分的权重表——同样一套堆操作的属性，在中单和辅助身上值的钱完全不同，越往后差得越开
- 创建时另选出身档位（网吧野生 / 普通家庭 / 体系青训，影响反应、对线与体力初值，不占分配点），另有24点分配七项属性
- 20个电竞天赋随机抽3个、自定义 ID
- 14—16岁青训营成长，每月3执行点，每2个月无重复优先的艰难事件
- 每半年关键人物剧情；父亲、陈安安、周骁教练独立立绘
- 16岁三线分流：LDL 二队 / 高校电竞 / 韩国青训，海外路线强制分手
- 18岁进入转会市场，LPL 17队与 LCK 10队
- 所有行动与比赛判定统一经由「有效属性」= 属性 × 状态精力系数；精力见底时反应和操作掉得最狠，心态几乎不受影响
- 有效属性、对手强度和随机共同决定的比赛简报与手伤（腱鞘炎、手腕劳损、颈椎压迫、长期失眠、心态崩盘）
- 赛季赛程在赛季初就排定，一年12个月的节奏是固定的：

  | 月份 | 内容 |
  | --- | --- |
  | 1—5 | 春季赛常规赛 |
  | 6 | MSI 季中冠军赛 |
  | 7—8 | 夏季赛常规赛 |
  | 8—9 | 夏季赛季后赛两轮，争 S 赛门票 |
  | 11 | S 赛全球总决赛（拿到门票才排得上，否则照常打联赛） |
  | 12 | 转会期，无比赛，年度评选与合同结算 |

- 主界面常显下一场对手、主客与还有几个月，「赛程」页可查一整季日程，请假缺阵的场次也会留痕
- 「结束本月」后先出赛前预告——写明对手、双方实力星级、你的精力状态与预估首发率，三个选项就是本场定位（打输出核心 / 稳住运营 / 全场压制），看完对手再决定怎么打
- 每场出场触发 2 个关键时刻（越塔单杀、团战混乱、大龙团、BP 最后一手、守家、入侵野区、一句话的分量……），成功率由关键属性、状态、精力、天赋与流派共同决定并锁在 15%—85%
- 高风险选择成功可拿人头、评分大涨并留下「名局」；失败则浪费机会，还有 35% 概率被对面反打
- 每 3 场一轮教练挑战，稳妥/进攻/冒险三选一；失败只扣少量状态，不扣信任，避免越输越难
- 四条训练流派（大核 MEC / 压制 LAN·REA / 运营 AWA·END / 指挥 COM），20/60/120 经验三级成长，二级解锁专属比赛选项；流派等级抬高对应属性的成长天花板，没有流派兜着的属性练到88左右就爬不动了
- 五条训练各自直连属性；赛前选「全场压制」在 AWA 不足时是净负收益
- 同月重复同一训练收益降至 60%、伤病风险上升；行动组合有额外奖励；未用完的执行点自动转为休息
- **比分永远是合法的系列赛局分**：常规赛 BO3（2-0 / 2-1），季后赛与国际赛淘汰赛 BO5（3-0 / 3-1 / 3-2）。电竞没有平局，`toSeries()` 是所有比分的唯一出口
- 国际赛事：MSI 与 S 赛共用同一套引擎，难度差别只来自对手池——MSI 只有各赛区春季冠亚军，S 赛淘汰赛池 84~93。抽签、逐场对阵和战报都带赛区旗帜（LPL 🇨🇳 / LCK 🇰🇷 / LEC 🇪🇺 / LTA 🇺🇸 / LCP 🌏），夺冠后的领奖台对话加入奖杯视觉
- 淘汰赛 2-2 后进决胜局，三个选择（抢先手强开 / 按训练赛那样打 / 等对面先动）读不同属性，精力见底时「等对面先动」会反超
- 联赛积分榜：青训队 / 高校 / LPL / LCK 各有一张，你的每一场都直接算进排名；赛季末排第一就是冠军，榜尾三名算保级失败
- 宿敌江彻：同届青训队里天赋最好的那一个，16岁走你没走的那条路，18岁起每个赛季和你比联赛击杀；同联赛对阵会当场较量，年度评选揭晓对位胜负，退役结局有你们各自的收尾
- 年度最佳选手、联赛冠军、奖杯陈列、25项成就、本地生涯排行
- 三档难度（标准/困难/严酷）：影响成长速度、属性软上限、伤病、入选门槛与收入
- **生涯远比足球短**：22—24岁起反应逐年衰退，26—28岁退役并结算生涯结局
- 合同月薪逐月发放、生活开销与欠款利息，金钱可用于礼物/家用/康复并计入生涯积分
- 每赛季教练KPI目标，达成给奖金与信任，失败会被雪藏、降薪甚至下放
- 分手后可复合支线（含海外线），关系值越高，比赛发挥与状态加成越大
- 家庭状况与安安关系并列显示在侧栏，两者都抬高状态的长期基线：家里安稳你状态更稳，家里出事你持续下滑
- 高校联赛对手为重庆本地高校电竞社；侧栏常显资金，独立「资产」页 19 件商品分五类，含被动收入与求婚结婚
- 本机自动存档，无后端、无外部CDN、无数据上传

## 测试

```bash
node --check app.js
node tests/structure.test.mjs
```

`tests/structure.test.mjs` 有 34 组断言，守住分路权重和为 1、赛事日历、赛程合法性、比分不出现平局、赛区旗帜齐全、存档迁移，以及五条分路各跑一整段生涯到退役不抛异常。

重建独立单文件版：

```bash
python3 build_single.py
```

推到 `main` 会自动触发 GitHub Actions：先跑 `structure.test.mjs`，再校验单文件版与源码同步，
两关都过才部署 Pages。所以改完源码**必须重新跑一次 `build_single.py` 并一起提交**，否则 CI 会拦下来。
